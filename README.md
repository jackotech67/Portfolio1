## Features

- Responsive desktop, tablet and mobile layouts
- Responsive hamburger navigation for mobile devices
- Smooth scrolling to the contact section
- Automatic image carousel with pause-on-hover functionality
- Expandable project information using "See more / See less" controls
- Interactive hover effects and 3D flip cards
- Responsive CSS Grid and Flexbox layouts
- CSS variables for consistent colours and typography
- Custom domain and HTTPS deployment through GitHub Pages
